# 示例

下面所有输出都能通过 `scripts/validate_prompt.py` 的校验。

## 1. 单事件模式——主体在空间中移动，使用跟随镜头

**输入：** `一个小女孩在公园小路上骑自行车，镜头跟拍。`

**输出：**

一个扎着双马尾的小女孩骑着一辆浅蓝色自行车，沿着秋日公园的林荫小路前行。小女孩约六岁，穿着鹅黄色毛衣、牛仔背带裤和白色运动鞋，头戴一顶粉色儿童头盔，车把上挂着彩色流苏。起初，小女孩双手握紧车把，以平稳的速度踩着踏板向前骑行，流苏随风轻轻飘动。随后她微微抬头，望向路旁飘落的金黄树叶，嘴角露出开心的笑容，双脚有节奏地蹬着踏板。整个过程中，她沿着蜿蜒的小路匀速前进，双马尾随着骑行轻轻摆动，车轮碾过落叶发出细碎的沙沙声。小路两旁是高大的银杏树，金黄的叶子在微风中缓缓飘落，远处是铺满落叶的草坪。戴粉色头盔、穿鹅黄毛衣的小女孩始终清晰醒目。镜头跟随小女孩移动，始终将小女孩保持在画面中央。平视中景。柔和的侧逆光穿过树叶，在路面投下斑驳光影，金黄与浅蓝形成和谐的色调。焦点清晰，质感细腻。轻松而愉快。电影级写实摄影风格。

**要点**
- 小女孩沿小路持续移动，所以保留跟随，并且只用一句标准跟随句（“镜头跟随……移动，始终将……保持在画面中央”）；大范围移动配中景。
- 骑行被写成可以一直持续的匀速前进，而不是骑到某处就结束；速度用“平稳”“匀速”保持自然。
- 沙沙声对应画面中可见的车轮碾过落叶（声画一致）；背景只补充了环境，没有新增人物。

## 2. 单事件模式——主体静止时仍要有可见动作

**输入：** `一只橘猫趴在窗台上晒太阳。`

**输出：**

一只橘色短毛猫慵懒地趴在洒满午后阳光的木质窗台上晒太阳。橘猫体型圆润，毛色为明亮的橘黄色并带有浅色虎斑条纹，胸口是奶白色，眼睛呈琥珀色。起初，橘猫侧卧在窗台正中，眯着眼睛，腹部随着呼吸缓慢起伏。随后它伸出前爪舒展身体，打了一个小小的哈欠，又把下巴搁回交叠的前爪上。与此同时，它的尾巴尖有节奏地左右轻摆，耳朵偶尔随着窗外的鸟鸣微微转动。窗外，几片绿叶在微风中轻轻摇曳，一只小麻雀在晾衣绳上跳动，发出清脆的叫声。整个过程中，这只带浅色虎斑的橘猫始终保持放松的姿态。镜头保持静止，始终将橘猫保持在画面中央。平视中景。温暖的侧逆光勾勒出毛发轮廓，暖黄与淡绿形成和谐的色调。宁静而惬意。电影级写实摄影风格。

**要点**
- 橘猫待在原地，所以用静止镜头；主体基本不动，因此写了呼吸、伸懒腰、甩尾、转耳朵等持续的小动作。
- 鸟鸣对应画面中可见的麻雀（声画一致）。
- 结尾前再次锚定主体特征（“带浅色虎斑的橘猫”），风格标签放在最后。
- 全文约 270 个汉字，落在 150–350 的中段：场景简单时不必写到上限。

## 3. 逐事件流式模式——两个事件先后到达

### 事件 1

发给模型的 user message：

```text
已定稿的历史事件：无——这是序列中的第一个事件。

待改写的新事件：
一位老渔夫清晨坐在木码头上补渔网。

请仅将上面的新事件改写为一条完整的 prompt，遵循多事件流式模式的规则。
```

输出（成为已定稿的历史）：

清晨，一位年迈的渔夫坐在木码头上，耐心修补搭在膝头的大渔网，身旁是平静的港湾。老渔夫留着短白胡子，皮肤黝黑、布满皱纹，头戴褪色的蓝色针织帽，身穿厚灰色羊毛衫，脚踩橄榄绿色胶靴。起初，老渔夫将一段破损的绿色尼龙网举向晨光，眯眼查看断开的网眼。随后他把织网梭穿过破洞，稳稳拉紧网线，打上一个小结。整个过程中，他不断重复穿梭、拉线、打结的平稳节奏，一段段挪动膝上的渔网，肩膀随呼吸轻轻起伏。他身后，几艘小渔船在如镜的水面上随波轻晃，薄雾低低飘过港湾，几只海鸥在高空滑翔，鸣叫声隐约可闻。戴蓝色针织帽的白胡子老渔夫始终是码头上安静的视觉中心。镜头保持静止，始终将老渔夫保持在画面中央。平视中远景。粉金色晨光从侧面洒下，勾勒出他脸上的皱纹与渔网的纤维，水面泛着清冷的蓝色阴影。焦点清晰，质感细腻。宁静而沉思。电影级写实摄影风格。

### 事件 2

发给模型的 user message：

```text
已定稿的历史事件（只读上下文——不要改写或重复）：
事件 1（已改写并定稿）：清晨，一位年迈的渔夫坐在木码头上，……电影级写实摄影风格。

待改写的新事件：
他抬起头，一个小男孩提着一桶鱼跑了过来。

请仅将上面的新事件改写为一条完整的 prompt，遵循多事件流式模式的规则。
```

（实际请求中要放入事件 1 的完整文本，不能省略。）

输出：

清晨的木码头上，戴褪色蓝色针织帽、留着短白胡子的老渔夫停下补网的动作，一个提着一桶鱼的小男孩正沿着木板向他跑来。老渔夫依旧穿着厚灰色羊毛衫和橄榄绿色胶靴，绿色尼龙渔网仍搭在膝头。小男孩约七岁，身穿黄色雨衣和红色胶靴，双手提着一只装满银亮鲜鱼的旧铁桶。起初，老渔夫从渔网上抬起头，脸上露出温和的笑容。随后，小男孩以自然的步速从画面左侧小跑进来，铁桶微微摇晃，他在老渔夫身旁放慢脚步。与此同时，男孩把铁桶斜过来展示鱼获，老渔夫俯身点头，用手指指着桶里的鱼，两人比划着交谈。他们身后，小渔船在如镜的港湾里随波轻晃，薄雾低低飘过水面。整个过程中，白胡子老渔夫与穿黄色雨衣的小男孩始终紧挨在码头中央。镜头保持静止，始终将老渔夫和小男孩保持在画面中央。平视中远景。粉金色晨光从侧面洒下，水面泛着清冷的蓝色阴影。温暖而温情。电影级写实摄影风格。

**要点**
- 输入开头的“他”被替换成已确立的完整名词短语（“戴褪色蓝色针织帽、留着短白胡子的老渔夫”）。
- 老渔夫待在原地，所以事件 1 用静止镜头；事件 2 中没有任何需要跟随的动作，因此沿用同一套设置（平视中远景、静止），小男孩是走进既定画幅，而不是镜头重新构图。
- 老渔夫的服装、渔网、码头、晨光和港湾都原样延续。
- 虽然有历史上下文，这个事件依然使用完整的长度预算。

## 5. 单事件模式——从输入图片开始（图生视频）

**输入图片**（随请求附上，这里用文字转述）：一张照片。午后的农家小院里，一位银发在脑后挽成小髻的老奶奶坐在竹椅上，膝头放着竹编簸箕，正在剥青豌豆；她穿藏青色碎花短袖布衫和黑色宽松布裤，手腕上戴一只旧银镯，脚边放着一只白色搪瓷盆；身后是青砖墙和爬满丝瓜藤的竹架。阳光从侧面照来，平视中景，老奶奶位于画面中央。

**输入文字：** `奶奶在院子里剥豆子。`

**输出：**

午后的农家小院里，一位满头银发的老奶奶坐在竹椅上，膝头放着一只竹编簸箕，正低头剥着青豌豆。老奶奶约七十岁，银发在脑后挽成一个小髻，穿着藏青色碎花短袖布衫和黑色宽松布裤，手腕上戴着一只旧银镯。起初，她从簸箕里拿起一根饱满的豆荚，用拇指沿着豆荚缝轻轻一按，豆荚应声裂开。随后她把翠绿的豌豆拨进脚边的白色搪瓷盆，豆子落进盆里发出清脆的嗒嗒声。整个过程中，她不紧不慢地重复着拿荚、剥开、拨豆的动作，肩膀随着呼吸轻轻起伏。她身后是青砖墙，墙边的竹架上爬满丝瓜藤，几片宽大的叶子在微风里轻轻摇动。戴银镯、穿碎花布衫的银发老奶奶始终是小院里安静的视觉中心。镜头保持静止，始终将老奶奶保持在画面中央。平视中景。午后的阳光从侧面洒下，在她的银发和豆荚上勾出暖色的轮廓光，青砖墙上落着淡淡的叶影。焦点清晰，质感细腻。恬静而温馨。电影级写实摄影风格。

**要点**
- 开头写到的银发小髻、碎花布衫、银镯、簸箕、搪瓷盆、青砖墙和丝瓜藤，图里都有。输入文字只说了“奶奶”“院子”“剥豆子”，外貌和环境细节都来自图片，图里没有的东西一样也没加。
- 动作从图中剥豆的姿势接着往下写，变成拿荚、剥开、拨豆循环往复的节奏。
- 景别、角度和光线（平视中景、午后侧光）与图片一致；老奶奶坐着不动，所以用静止镜头，主体和图中一样居中。
- 图片是照片，风格标签保持写实。如果看不到图片，就只能写用户提到的这几样，不能自己编出碎花布衫或银镯。

## 6. 常见转换速查

| 输入片段 | 改写方式 |
|---|---|
| “无人机环绕灯塔拍摄”（主体静止） | `镜头保持静止，始终将灯塔保持在画面中央。高角度航拍全景。` |
| “镜头推近奔跑的运动员” | `镜头跟随运动员移动，始终将运动员保持在画面中央。`，配中景或全景 |
| “镜头缓缓横摇扫过连绵山脉”（没有明确主体） | 均衡的宽景，写 `镜头保持静止。`，不虚构登山者 |
| “推近到她的眼睛”（她坐着不动） | 一开始就用她面部的特写并使用静止标准句，不写变焦 |
| “镜头跟着两位舞者穿过舞台” | `镜头跟随两位舞者移动，始终将两位舞者保持在画面中央。`，两人都不出画 |
| “巨龙最终落地并收起翅膀。” | “随后巨龙落地并收起翅膀。整个过程中，它不断缓缓舒张收拢的双翼，呼出缕缕细烟……” |
| 事件 3 输入：“它游向潜水员。” | “那条背鳍带缺口的大型灰礁鲨游向身穿黄色潜水服的潜水员……” |
| “热闹的集市，有香料摊、乐手和传令官” | 三类群体全部保留（“一群香料商贩”“一群街头乐手”“一位手持卷轴宣读的传令官”）；均衡的宽景；`镜头保持静止。`；不虚构主角 |
